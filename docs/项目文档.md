# 词忆 · 单词记忆网站 — 项目文档

> 项目名称：word-memory-backend  
> 访问地址：http://localhost:3500  
> 演示账号：demo / password123

---

## 1. 项目简介

「词忆」是一个帮助用户背单词的 Web 应用，采用 **Spring Boot + H2 + JPA** 构建后端，前端为绿色系暖白主题的静态页面，由 Spring Boot 统一托管。

核心能力：

- 用户注册登录
- 单词书与单词管理
- 艾宾浩斯间隔复习背单词
- 四选一单词自测
- 错词统计与分析
- 考试记录查询

---

## 2. 功能模块说明

| 模块 | 说明 | 后端包路径 | 前端页面 |
|------|------|-----------|---------|
| 用户认证 | 注册、登录、Token 鉴权 | `controller/AuthController` | 登录 / 注册页 |
| 单词书管理 | 单词书 CRUD、单词增删改查 | `controller/WordBookController` | 单词书页 |
| 背单词 | 艾宾浩斯算法安排复习 | `controller/MemorizeController` | 背单词页 |
| 单词自测 | 四选一出题与评分 | `controller/QuizController` | 自测页 |
| 错词统计 | 错词列表与汇总 | `controller/WrongWordController` | 错词页 |
| 考试记录 | 历史成绩与答题明细 | `controller/ExamRecordController` | 记录页 |

### 艾宾浩斯复习间隔

新词答对后，下次复习间隔依次为：

**5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天**

答错则重置到第一阶段，并记入错词本。

## 3. 技术架构

```
浏览器（index.html + CSS + JS）
        ↓ HTTP / JSON
Spring Boot 后端（端口 3500）
        ↓ JPA
H2 内存数据库
```

| 层次 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3.2 |
| 持久层 | Spring Data JPA |
| 数据库 | H2（内存模式） |
| 密码加密 | BCrypt |
| 认证方式 | Token（请求头 `Authorization: Bearer xxx`） |
| 前端 | HTML + CSS + JavaScript（无独立构建） |

## 4. 数据库设计

| 表名 | 实体类 | 说明 |
|------|--------|------|
| users | User | 用户账号 |
| word_books | WordBook | 单词书 |
| words | Word | 单词（拼写、音标、释义、例句） |
| user_word_progress | UserWordProgress | 用户每个单词的复习进度 |
| wrong_word_records | WrongWordRecord | 错词记录 |
| exam_records | ExamRecord | 考试记录（自测成绩） |
| exam_answers | ExamAnswer | 每道题的答题明细 |

### 表关系（简要）

- 一个用户可创建多本单词书（`word_books.user_id`）
- 一本单词书包含多个单词（`words.word_book_id`）
- 用户对每个单词有独立的复习进度（`user_word_progress`）
- 自测提交后生成考试记录和答题明细（`exam_records` → `exam_answers`）

H2 控制台：http://localhost:3500/h2-console  
JDBC URL：`jdbc:h2:mem:wordmemory`，用户名 `sa`，密码留空。

## 5. 接口说明

所有接口返回统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1718822400000
}
```

除登录、注册外，需在请求头携带：`Authorization: Bearer <token>`

### 5.1 用户认证

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 注册 |
| POST | /api/auth/login | 登录，返回 token |
| POST | /api/auth/logout | 退出 |
| GET | /api/auth/me | 当前用户信息 |

### 5.2 单词书

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/wordbooks | 单词书列表 |
| POST | /api/wordbooks | 创建单词书 |
| PUT | /api/wordbooks/{id} | 修改单词书 |
| DELETE | /api/wordbooks/{id} | 删除单词书 |
| GET | /api/wordbooks/{id}/words | 单词列表 |
| POST | /api/wordbooks/{id}/words | 添加单词 |

### 5.3 背单词

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/memorize/today?wordBookId=1&limit=20 | 今日待复习 |
| POST | /api/memorize/review | 提交复习 `{ "wordId": 1, "correct": true }` |
| GET | /api/memorize/progress?wordBookId=1 | 学习进度 |

### 5.4 自测

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/quiz/generate | 生成题目 `{ "wordBookId": 1, "count": 10 }` |
| POST | /api/quiz/submit | 提交答案并计分 |

### 5.5 错词与记录

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/wrong-words | 错词列表 |
| GET | /api/wrong-words/stats | 错词统计 |
| GET | /api/exams | 考试记录 |
| GET | /api/exams/{id} | 考试详情 |

## 7. 运行方式

### 环境要求

- JDK 17+
- Maven 3.9+

### 启动

```bash
cd ~/Projects/word-memory-backend
mvn spring-boot:run
```

看到 `Tomcat started on port 3500` 后，浏览器访问 http://localhost:3500。

### 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 浏览器打不开 | 服务没启动 | 执行 `mvn spring-boot:run` |
| 端口被占用 | 3500 已有进程 | `lsof -i :3500` 然后 `kill <PID>` |
| 接口 401 | 未登录或 token 过期 | 重新登录 |

## 8. 本项目的 Git 分支管理

本项目采用 **Git Flow** 策略管理代码。

### 8.1 分支说明

| 分支 | 在本项目中的用途 |
|------|----------------|
| **main** | 存放可交付的稳定版本（如课程答辩、演示用） |
| **develop** | 日常开发主线，当前所有功能在此分支 |
| **feature-xxx** | 开发某个具体功能时临时创建 |

### 8.2 本项目实际分支记录

```
develop（当前开发分支）
├── feat(backend): 实现 Spring Boot 后端全部模块
├── feat(frontend): 添加绿色系前端页面
└── docs: 添加项目文档
```

后续开发示例：

| 要做的事 | 分支名 |
|---------|--------|
| 加「单词收藏」功能 | `feature-word-favorite` |
| 修自测选项 bug | `fixbug-quiz-options` |
| 准备 v1.1 发布 | `release-1.1` |

### 8.3 日常操作流程

```bash
# 1. 切到开发主线
git checkout develop

# 2. 为新功能建分支（举例：加收藏功能）
git checkout -b feature-word-favorite

# 3. 写代码、提交（格式见下一节）
git add .
git commit -m "feat(wordbook): 添加单词收藏功能"

# 4. 合回 develop
git checkout develop
git merge --no-ff feature-word-favorite
git branch -d feature-word-favorite
```

## 9. 本项目的 Git 提交规范

### 9.1 提交格式

```
类型(模块): 做了什么
```

### 9.2 本项目的模块（scope）对照表

写提交信息时，**模块名用下表里的**，不要用泛泛的 `update`：

| scope | 对应内容 | 举例 |
|-------|---------|------|
| auth | 登录、注册、Token | `feat(auth): 添加记住密码功能` |
| wordbook | 单词书、单词 CRUD | `feat(wordbook): 支持导入 CSV 单词` |
| memorize | 艾宾浩斯背单词 | `fix(memorize): 修复复习时间计算错误` |
| quiz | 四选一自测 | `feat(quiz): 增加计时功能` |
| wrong | 错词统计 | `fix(wrong): 错词列表分页显示` |
| exam | 考试记录 | `feat(exam): 导出成绩单` |
| frontend | 前端页面样式交互 | `feat(frontend): 添加深色模式` |
| backend | 后端通用改动 | `refactor(backend): 统一异常处理` |

### 9.3 类型说明

| 类型 | 什么时候用 |
|------|-----------|
| feat | 加了新功能 |
| fix | 修了 bug |
| docs | 只改了文档（如本文档） |
| style | 只改了格式、样式，不影响逻辑 |
| refactor | 重构代码 |
| chore | 改配置、依赖等 |

### 9.4 本项目已有提交示例（参考写法）

```
feat(backend): 实现单词记忆 Spring Boot 后端
feat(frontend): 添加绿色系暖白主题前端页面
docs: 添加项目文档
```

### 9.5 IDEA 提交建议

在 IDEA 中安装 **Git Commit Template** 插件，提交时：

1. 选类型 → feat / fix / docs …
2. 填模块 → auth / wordbook / quiz …（用上表）
3. 填描述 → 用中文写清楚做了什么
